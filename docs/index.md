## How to use this site

<div class="hb-howto">
  <div class="hb-howto__item"><span class="hb-howto__num">1</span><div><strong>Follow the 20-day plan.</strong> Tick each day as you finish it.</div></div>
  <div class="hb-howto__item"><span class="hb-howto__num">2</span><div><strong>Read each skill top to bottom.</strong> Every page starts with a plain-words section, then goes deep.</div></div>
  <div class="hb-howto__item"><span class="hb-howto__num">3</span><div><strong>Tick sections as you read them.</strong> Use the ✓ button next to each heading. A skill is marked done when every section is ticked, or with "Mark skill as done".</div></div>
  <div class="hb-howto__item"><span class="hb-howto__num">4</span><div><strong>Practise out loud.</strong> Answer the practice questions without looking, then revisit weak sections.</div></div>
</div>

Progress is saved in this browser. Use **Export** and **Import** below the dashboard to move it between devices, and **Reset all progress** to start again from the beginning.
